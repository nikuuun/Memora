# Design files

Reference material from the design side of Memora. Nothing in this folder is part of the app build
(it is excluded from `tsc` and ESLint).

- `Linnie_template_layouts.png` — the 10 starter template layouts (Classic Grid, Hero + Three,
  Polaroid Stack, Film Strip, Magazine Cover, Mosaic, Then & Now, Story Trio, Scrapbook, Year in Photos).
- `figma-make/` — the Figma Make web prototype (Vite + React + Tailwind). `src.zip`, `public.zip`
  and `make.zip` hold its source.
- `Memora-Mobile/` — an Expo SDK 54 adaptation of the Figma design, built on the original starter.
  Kept for reference: its theme and home screen are to be ported into the main app.

The app itself lives in the repo root (`app/`, `src/`). Work from `main` on your own branch and
open a pull request rather than uploading files directly.
